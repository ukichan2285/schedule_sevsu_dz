# Бот: новое меню заполнения ДЗ («предмет → дата»)

Изменение от 26.10.2026. Заменяет старый путь «неделя → день → пара», где приходилось
листать недели, чтобы найти следующую практику по предмету.

Файл: `app/bot.py` (единственный изменённый).

## Как работает

1. `/homework`, `/set_homework`, `/dz` или кнопка «📝 Задать ДЗ» → **список предметов**
   (только те, у которых есть хотя бы одна не-лекция).
2. Нажатие предмета → **его пары вперёд от сегодняшнего дня** (до +8 недель):
   `26.10 (Пн) · #3 · 11:50 · сегодня`
3. Нажатие пары → карточка ввода ДЗ (текст Markdown и/или фото), как раньше:
   «✅ Готово», «🗑 Очистить ДЗ», «« К датам».
4. Кнопка «📜 Прошедшие пары» — до 6 последних пар предмета до сегодняшнего дня,
   чтобы поправить старое ДЗ.

## Детали реализации

| Элемент | Значение |
|---|---|
| Callback: предметы | `hw:subjects` |
| Callback: будущие пары | `hw:subj:<key>` |
| Callback: прошедшие пары | `hw:past:<key>` |
| Callback: карточка ДЗ | `hw:l:<schedule_id>` (как было) |
| `key` предмета | `md5(subject.strip().lower())[:10]` — стабилен, ≤64 байт вместе с префиксом |
| Хелперы | `_subject_key`, `_resolve_subject`, `_subjects`, `_subject_lessons`, `_lesson_button_label`, `_send_subjects` |
| Источник дат | колонка `Schedule.date` (DateTime), а не `period_start` + `day_of_week` |
| Лекции | отфильтровываются существующей `is_lecture()` — ДЗ на них не задают |

Сортировка предметов: сначала те, у кого ближайшая будущая пара раньше, затем — по алфавиту.
Подпись кнопки пары: дата, короткий день недели, номер пары, **подгруппа** (если есть),
время, пометки «сегодня»/«завтра», `📝` если ДЗ уже заполнено. Обрезка до 60 символов.

Подгруппа добавлена после проверки на боевой БД: у «Физической культуры» пары идут
подгруппами 1 и 2 с одинаковыми датой/номером/временем, без пометки кнопки были неразличимы.

## Удалено

- неиспользуемые после этого `current_monday()` и импорт `fmt_week`.

## Нюансы

- Старые сообщения с кнопками прежнего флоу (`hw:weeks` и т.п.) теперь не обрабатываются —
  бот просто игнорирует неизвестный `kind`. Достаточно заново вызвать `/homework`.
- Список предметов читает все занятия из БД (≈сотни строк) и группирует в Python — на текущих
  объёмах (8 недель, 60 занятий) это незаметно.
